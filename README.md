# Kriuk Emas — Renyahnya Bikin Rindu

Kriuk Emas adalah website katalog menu lumpia yang dibuat
menggunakan Express.js dan EJS.

## Fitur

- Menampilkan daftar menu lumpia.
- Memfilter menu berdasarkan kategori menggunakan req.query.
- Menampilkan detail menu berdasarkan ID menggunakan req.params.
- Menampilkan halaman 404 jika menu tidak ditemukan.
- Menggunakan EJS partial untuk header dan footer.
- Menggunakan CSS untuk mempercantik tampilan website.
- Mengirimkan data dari controller ke halaman melalui res.render().

## Teknologi

- Node.js
- Express.js
- EJS
- HTML dan CSS

## Cara Menjalankan

1. Pastikan Node.js sudah terpasang.
2. Buka terminal di folder proyek.
3. Jalankan perintah npm install.
4. Jalankan perintah npm start.
5. Buka http://localhost:3000 di browser.

## Data

Data menu disimpan dalam array lokal di folder data.
Website ini tidak menggunakan database.
